裴蜀定理（Bézout's Lemma），也称贝祖定理，是数论中关于最大公约数的一个基本且重要的定理。它揭示了两个或多个整数的线性组合与它们最大公约数之间的深刻联系。

📜 定理内容

对于任意两个不全为零的整数 a 和 b，设它们的最大公约数为 d（即 gcd(a, b) = d），那么：

1.  存在性：一定存在整数 x 和 y，使得线性不定方程 ax + by = d 成立。
2.  倍数关系：对于任意整数 x 和 y，ax + by 的值一定是 d 的倍数。

一个非常重要的推论是：两个整数 a 和 b 互质（即 gcd(a, b) = 1）的充分必要条件是，存在整数 x 和 y 使得 ax + by = 1。

🔢 举例说明

以 a = 12 和 b = 42 为例：
*   它们的最大公约数是 gcd(12, 42) = 6。
*   根据裴蜀定理，一定存在整数 x 和 y 使得 12x + 42y = 6。
*   例如，当 x = -3, y = 1 时，12 * (-3) + 42 * 1 = -36 + 42 = 6，等式成立。

🔄 定理推广

裴蜀定理可以推广到多个整数的情形。对于 n 个不全为零的整数 a₁, a₂, ..., aₙ，设它们的最大公约数为 d，那么一定存在整数 x₁, x₂, ..., xₙ，使得：
a₁x₁ + a₂x₂ + ... + aₙxₙ = d

🛠️ 求解方法与应用

裴蜀定理的证明是构造性的，它给出了求解系数 x 和 y 的方法，即扩展欧几里得算法。

该定理在多个领域有广泛应用：
*   求解不定方程：判断线性不定方程 ax + by = c 是否有整数解。该方程有解的充要条件是 c 能被 gcd(a, b) 整除。
*   密码学：在RSA等加密算法中，用于计算模逆元。
*   算法竞赛：是解决许多数论相关问题的基础工具。
